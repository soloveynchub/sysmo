## AI и защита ключа

- Timeweb `/models` успешно проверил предоставленный ключ, модель `openai/gpt-4.1-mini` доступна.
- Реальные структурированные ответы получены и отображены в панели. Результат с расходом токенов сохраняется в локальной БД и переживает restart.
- Настройки через UI сохраняются при пустом поле замены ключа; ключ не возвращается в браузер. Поле ввода имеет type=password.
- Ключ проверен на отсутствие в исходниках, frontend/dist, документации и JSON локального API. БД credentials имеет права 0600 и находится вне репозитория. SQL-файлы дополнительно исключены `.gitignore`.
- Неправильный session token получает 403; корни вне home — 400; неизвестный ID снимка — 400. Экспорт проверен на отсутствие реальных имён/путей.
- В model messages передаются только обезличенные факты, без tools. Нет автоматической очистки или отправки по таймеру.
