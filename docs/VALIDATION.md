# Проверка версии 0.1.0

Проверено 15 сентября 2026 на MacBook Pro Mac15,3, Apple M3, 4P + 4E, 10 GPU-ядер, 8 ГиБ, macOS 26.5.1.

## Выполнено

- Сборка Rust release и TypeScript/Vite; пять Rust-тестов: классификация, блокировка удалённого Docker, длительность всплеска, взвешенная история и compaction.
- Реальные CPU/RAM/swap/температуры/вентиляторы/батарея/сеть/дисковые счётчики через локальные источники.
- Контрольный Node-процесс: до 98.4% CPU одного ядра, около 48 МиБ памяти, до 14.7 МиБ/с записи; распознаны Node и рабочая папка проекта.
- HTTP: свой origin 200, чужие Origin и Host 403, запись 405. Агент привязан к loopback.
- UI проверен на ширинах 430, 600, 800, 1024 и 1440; светлая/тёмная темы, графики и подробности процессов. Схема M3 проверена на 430 и 1440. Ошибок браузерного console в проверке не обнаружено.
- LaunchAgent устанавливается и перезапускается; WebSocket восстанавливает связь, база истории сохраняется между перезапусками.

## Ограничения доказательств

- При контрольной нагрузке агент: среднее 6.8% одного CPU-ядра, максимум physical footprint около 52 МиБ. Это не idle benchmark. Требование менее 1% CPU не выполнено.
- Docker daemon был недоступен. Пустое состояние проверено, работающие контейнеры — нет.
- Фактический reboot и другие модели Mac не проверялись.
- На защищённых системных процессах часть метрик недоступна.
- Во время ранней разработки исправлен перевод Mach ticks в наносекунды. Локальная история, накопленная до исправления, не пригодна для точной ретроспективы CPU процессов. Эта база в репозиторий не включается.
- Скриншоты README предоставлены автором до последнего уточнения доступности счётчика ANE; интерфейс теперь различает недоступный счётчик и нулевую мощность.

Репозиторий содержит исходники и скриншоты, не содержит локальную историю, логи, toolchain или собранные бинарники.

## Подготовка публикации

- `scripts/setup.sh` выполнен на проверенной машине: npm ci (0 известных уязвимостей по npm audit), TypeScript/Vite, 5 Rust-тестов, release build — успешно.
- `manage.py install/status/stop/start/restart` проверены на работающем LaunchAgent; агент оставлен запущенным.
- После перезапуска аппаратные данные появились в API и UI. Канал энергии ANE на этом M3 доступен, последний замер — 0 W.
- Синтаксис shell/Python, локальные ссылки README и состав публикации проверены. Первоначальная установка отсутствующих инструментов на чистом Mac не проверялась.
